🎮 Back to the Past
Back to the Past is a 2D puzzle-platformer built in Unity where the player can switch between two timelines — past and present — to solve puzzles, destroy enemies, and escape the level. Each timeline presents a different version of the world, requiring players to think strategically and make smart use of the time-switch mechanic.

🚀 Features
🕹️ Time Travel Mechanic: Switch between the past and present to access alternate versions of the level.

💣 Bomb Throwing: Use bombs to destroy enemies and destructible objects.

⛓️ Puzzle Solving: Navigate through levels by strategically using time shifts and environment interactions.

🧠 State Machines: Separate player, enemy, and bomb behavior into clean state-based systems.

🌀 Dynamic Traps: Avoid or disable traps that vary across timelines.

🧩 Tech Highlights
Unity (C#)

Architecture: Model-View-Controller (MVC)

State Pattern: Used for player, enemy, and bomb behaviors

Object Pooling: Optimized bomb spawning

Service Locator: Centralized service access

Observer Pattern: Decoupled event communication

Cinemachine: For dynamic and smooth camera movement

📦 How to Play
Move – Arrow keys or WASD

Jump – Spacebar

Switch Timeline – T

Throw Bomb – Left Click

Solve puzzles, destroy barriers, and find the key to escape.


Press Play and start your time-traveling adventure!
